# Celestial Sandbox

A Vite-based web project for a celestial-body sandbox.

## Run locally

1. Install [Node.js](https://nodejs.org/) if it is not already installed.
2. Open this folder in VS Code.
3. In the terminal, run `npm install`.
4. Run `npm run dev` and open the local URL printed by Vite.

## Project layout

- `index.html` — home page.
- `screens/` — individual pages (`info.html`, `settings.html`, `simulation.html`).
- `stylesheets/main.css` — shared styles and page-specific sections in one stylesheet.
- `scripts/ambient-bg.js` — animated background stars and the star visibility setting.
- `scripts/soundtracks.js` — background music and its setting.
- `sounds/` — audio assets (if present locally).

`node_modules/` is generated by `npm install` and should not be moved into a separate folder or committed to source control.
